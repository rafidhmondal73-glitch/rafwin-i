# RAFWN — starter website

Static, responsive landing site for RAFWN.space.

## Included
- Responsive mobile/desktop layout
- Tech-style animated hero/orbit
- Scroll reveal animations
- Animated stats counters
- Magnetic CTA interaction
- Mobile navigation
- Services, work, process, stack and contact sections
- SEO/social metadata
- Accessible form labels and reduced-motion support

## Run locally
Open `index.html` directly, or serve the folder with any static server.

## Before launch
1. Replace demo project cards with real work.
2. Connect the contact form to Formspree, Resend, a serverless function, or your own API.
3. Add your final logo SVG/PNG and favicon.
4. Add analytics only if you need them.
5. Deploy to Vercel, Netlify, Cloudflare Pages, GitHub Pages, or any static host.
